# datasets

Dataset download scripts and license/accessibility notes for CICIoMT2024 (primary)
and WUSTL-EHMS-2020 (secondary, network+clinical fusion). Raw dataset files
themselves are gitignored — never committed to the repository.

No dataset is downloaded or processed yet. That is explicitly Phase 3 work, done
only after license and accessibility are verified (per architecture spec Section 6)
— no performance claim is made about a dataset until it has actually been used.
